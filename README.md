# Olist巴西电商平台全链路SQL数据分析项目
## 一、项目背景
Olist是巴西本土头部综合电商平台，采用第三方多卖家入驻模式，覆盖全国27个州的消费市场。本项目基于平台2016年9月至2018年8月的真实经营数据，通过MySQL完成数据存储与多维度指标计算，结合Python实现自动化可视化，全面拆解平台运营现状、用户价值与供应链痛点，输出可落地的业务优化方案。

## 二、数据集与技术栈
### 2.1 数据集说明
原始数据集来源：[Kaggle Olist E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
包含8张核心关联业务表，总数据量120万+行，覆盖电商全业务链路：
- 订单主表：99441条订单全生命周期记录
- 订单明细表：112650条商品交易明细
- 用户表：99441条用户地域与身份信息
- 商品表：32951条商品基础属性
- 支付/评价/卖家/地理表：覆盖支付方式、用户评分、卖家分布、全国坐标信息

### 2.2 技术实现
- 数据库：MySQL 8.0
- 数据处理：Python 3.9 + Pandas + SQLAlchemy
- 可视化：Matplotlib
- 分析方法：多表联查、CTE公共表达式、窗口函数、RFM用户价值分层模型

## 三、核心分析结论
### 3.1 经营大盘
- 平台总交易额1541.98万元，有效交付订单96478单，订单完成率97.02%
- 独立付费用户93358人，单用户平均下单1.03次，**用户复购率仅3%**，平台严重依赖新用户
- 平均配送时长12.5天，整体符合巴西市场水平，但6.77%的订单存在超时配送问题

### 3.2 支付与用户
- 信用卡是绝对主流支付方式，贡献81.34%的平台营收；银行票据(Boleto)占比18.61%
- 用户高度集中在东南部发达地区，圣保罗州(SP)用户占比41.94%，贡献37.42%的总营收
- 消费结构呈金字塔型：仅4.57%的高消费用户贡献了平台绝大多数高利润订单

### 3.3 商品与供应链
- 家居床品、美妆健康、运动休闲是三大核心类目，占据平台半壁江山
- 美妆健康类目虽然销量第二，但营收最高，单品均价130.16元，盈利能力最强
- 手表礼品类目单品均价201.14元，是高潜力高客单价品类

### 3.4 RFM用户价值分层
基于RFM模型将用户划分为8个价值层级，核心发现：
- 仅39.2%的中高价值用户贡献了平台71.77%的营收，完全符合二八定律
- 重要保持用户(16.44%用户占比)贡献30.17%营收，是平台核心利润来源
- 重要发展用户潜力巨大，重要挽留用户流失风险高，需针对性运营

## 四、业务优化建议
1. **用户运营**：建立会员体系锁定核心高价值用户；定向唤醒沉睡大额用户；推出老带新奖励提升复购率
2. **商品供应链**：加大核心类目招商力度，保障热销商品库存；重点扶持高客单价类目
3. **物流体验**：在核心城市建立前置仓；优化偏远地区承运商；提升配送时效透明度

## 五、项目运行步骤
1. 安装依赖：
```bash
pip install -r requirements.txt
2. 本地安装 MySQL 8.0，创建数据库：
CREATE DATABASE olist_ecommerce DEFAULT CHARACTER SET utf8mb4;
3. 从 Kaggle 下载原始数据集，修改import_olist.py中的数据库密码和 CSV 文件路径，运行脚本导入数据
4. 执行sql/core_analysis.sql中的 SQL 语句，生成所有分析结果
5. 运行visual_analysis.py生成三张可视化图表
